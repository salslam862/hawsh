# حوشك 2.10.43 — تدقيق سلامة العقد ودورة العمل

- توسيع فحص سلامة لقطة اعتماد العقد ليتحقق أيضًا من بصمتي SHA-256 لصورة وثيقة البائع وصورة وثيقة الطرف الآخر.
- حفظ بصمات صور الوثائق داخل لقطة الاعتماد عند اعتماد العقد، دون تكرار صور الهوية نفسها داخل اللقطة.
- عند قراءة قائمة العقود، تظهر حالة اللقطة `VERIFIED` فقط إذا تطابقت بصمة اللقطة وبصمتا الصور مع المحتوى الحالي؛ وإلا تظهر `MISMATCH`. العقود القديمة التي لا تملك بصمة تبقى `LEGACY`.
- الحفاظ على مشاركة العقد كملف PDF، مع عدم إنشاء حركة مالية أو فاتورة تلقائيًا عند اعتماد العقد؛ تتم المعاملة المالية من مسارها المخصص لتجنب التكرار.
- تحديث إصدار التطبيق إلى 2.10.43 ومخابئ التخزين المؤقت.
- تنظيف حزمة التوزيع من قاعدة بيانات التشغيل المحلية؛ ينشئ التطبيق قاعدة بيانات فارغة عند أول تشغيل، ويُستخدم `npm run seed` فقط عند الرغبة في إضافة بيانات تجريبية.
