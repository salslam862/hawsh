# حوشك 2.10.48 — دورة الإيجار وربط الحجز والعقد والاستردادات

## مجموعات التغيير
1. إضافة مسار موثق لاستلام الأصل المؤجر وإعادته إلى حالة متاحة، مع منع تكرار الإرجاع.
2. دعم ربط العقد بالحجز المؤكد والتحقق من الأصل والطرف ونوع المعاملة.
3. حفظ رابط الحجز داخل لقطة اعتماد العقد وبصمتها الرقمية.
4. ربط الفاتورة بالحجز والعقد، وإظهار العلاقة في بيانات الفاتورة.
5. إضافة استرداد جزئي/كلي للفاتورة بحركة مصروف مستقلة، وسبب إلزامي ومعرّف منع تكرار.
6. تحديث واجهة الحجوزات لإظهار حالة الإيجار وزر إرجاع الأصل.
7. تحديث واجهة العقود لاختيار حجز مؤكد وملء الأصل والطرف وتواريخ الإيجار.
8. إضافة أعداد الإيجارات النشطة والمتأخرة إلى ملخص التقارير.
9. توسيع مطابقة المالية لكشف عدم تطابق روابط الحجز والعقد والفاتورة وحالة إرجاع الإيجار.
10. تحسين فحص تعارض حجوزات البيع والإيجار، وتحديث مخابئ التخزين المؤقت وتنظيف الحزمة.

## اختبارات
- `node --check src/server.js`
- `node --check public/app.js`
- `npm test`: 50 اختبارًا ناجحًا، دون فشل.
- يتضمن اختبار HTTP المتكامل: إنشاء العقد واعتماده، ربط فاتورة، تسجيل دفعة واسترداد idempotent، تأكيد حجز إيجار، ربط عقد وفاتورة بالحجز، تسليم الأصل ثم إرجاعه، ورفض تكرار الإرجاع.

## حدود التحقق
الاختبارات محلية وبقاعدة بيانات اختبار منفصلة. لم يتم اختبار النشر على Railway أو إجراء استرداد مالي حقيقي أو مشاركة PDF عبر هاتف فعلي. يجب أخذ نسخة احتياطية من بيانات الإنتاج قبل النشر.
