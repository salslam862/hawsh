# حوشك 2.10.32 — دقة عروض الشراء والسوم

- تمت متابعة العمل انطلاقًا من النسخة 2.10.31.
- أصبح السوم الحالي يُحسب من عروض الشراء المفتوحة ذات المبالغ الصحيحة فقط.
- عند رفض عرض أو تغييره أو قبوله، يعاد احتساب السوم الحالي حتى لا يبقى مبلغ عرض مرفوض ظاهرًا كسوم حالي.
- إذا لم توجد عروض مفتوحة صالحة، تُمسح قيمة السوم الحالي بدل الاحتفاظ بقيمة قديمة.
- تم تحديث إصدار ذاكرة التخزين المؤقت لتطبيق الإدارة والعميل.
- لم يُحذف أي قسم أو وظيفة موجودة عمدًا.
