# حوشك 2.10.20 — Offline Intake Sync

## الهدف
تحسين الاعتماد على ميزة الإدخال دون إنترنت الموجودة أصلًا، مع أقل تغيير ممكن في النسخة المستقرة السابقة.

## ما تم تغييره
- حفظ جلسة موظف/مدير الإدارة محليًا فقط كاحتياط عند فقد الإنترنت، حتى لا تختفي لوحة الإدارة عند إعادة فتحها دون اتصال بعد تسجيل دخول سابق.
- تشغيل مزامنة الإدخالات المؤجلة عند فتح لوحة الإدارة، وليس فقط عند فتح المنصة العامة.
- تشغيل المزامنة أيضًا عند عودة الصفحة للواجهة، بالإضافة إلى حدث عودة الاتصال، مع محاولة دورية كل 15 ثانية أثناء وجود الإنترنت.
- الإبقاء على `clientRequestId` لمنع تكرار الأصل أو المالك عند إعادة المحاولة.
- الإبقاء على IndexedDB كالتخزين الأساسي للطابور مع localStorage كخطة بديلة.

## ما لم يتم تغييره
- واجهات الإدخال الحالية.
- الأزرار والوظائف الحالية.
- API الحالي الخاص بالإدخال والمزامنة.
- منطق المالك، الصور، الأكواد، الحالات، الأغراض، الأسعار، والإيصالات.
- جميع ميزات النسخة السابقة.
