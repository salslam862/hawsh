# حوشك 2.10.38 — صور وثائق أطراف العقد

- أضيف خيار التقاط صورة بالكاميرا أو اختيار صورة من الجهاز لوثيقة البائع/مالك الأصل ووثيقة الطرف الآخر.
- الصيغ المدعومة JPG وPNG وWEBP، والحد الأقصى لكل صورة 1 ميغابايت.
- تُحفظ الصور داخل سجل العقد المحمي بواجهات الإدارة، وتظهر في قسم مستقل أسفل ورقة العقد المطبوعة.
- تُعرض تسمية كل صورة بحسب نوع الوثيقة المسجل لكل طرف.
- جرى تحديث ذاكرة التخزين المؤقت للوحة الإدارة.

ملاحظة: هذا الإصدار لا يغيّر شكل الأقسام الأساسية للورقة؛ يلحق قسم الوثائق في الأسفل. اختبر رفع الصور والطباعة في بيئة تجريبية قبل النشر، وفعّل نسخًا احتياطية وتقييد صلاحيات الوصول لأن الوثائق بيانات شخصية حساسة.
