# حوشك 2.10.35 — الملف المالي المتكامل

- ربط حركات سداد الفواتير بمعرّف الفاتورة.
- تسجيل زيادة المدفوع كدخل، وتسجيل خفض المدفوع كتسوية مصروف موثقة بدل تغيير الرقم بصمت.
- إضافة مقارنة بين قيمة المدفوع في الفاتورة وصافي الحركات المرتبطة بها إلى تقرير المطابقة.
- احتساب التقارير حسب تاريخ الحركة الفعلي مع حفظ وقت التسجيل منفصلًا.
- إظهار صافي الدخل/المصروف وعدد الحركات حسب التصنيف في بيانات التقرير.
- واجهة لتحديث المبلغ المدفوع على الفاتورة مع تأكيد المستخدم.

الصور الإلكترونية لهويات البائع والمشتري لم تُضف في هذا الإصدار؛ تُنفذ بعد إكمال خطوات المسار المالي كما طلب المستخدم، وتظهر أسفل ورقة عقد البيع مع تسمية نوع الوثيقة لكل طرف.
