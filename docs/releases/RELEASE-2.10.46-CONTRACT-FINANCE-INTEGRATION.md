# حوشك 2.10.46 — تكامل العقود والمالية ومنع التكرار

## نطاق الإصدار: خمس مراحل مدمجة
1. إعادة التحقق من حالة الأصل والغرض والحجوزات عند اعتماد العقد، لا عند إنشائه فقط.
2. منع اعتماد عقد بيع/إيجار منافس لأصل لديه عقد مماثل معتمد، والتحقق من نوع عقد التخزين.
3. التحقق من توافق نوع الفاتورة مع نوع العقد المرتبط.
4. إضافة مسار مستقل لتسجيل دفعات الفاتورة مع معرّف idempotency إلزامي، ومنع تجاوز الرصيد أو تكرار الحركة المالية عند إعادة الطلب.
5. توسيع مطابقة المالية لكشف اختلافات روابط العقود والفواتير وعربون الحجوزات، وإضافة زر «تسجيل دفعة» في لوحة الفواتير.

## التغييرات التشغيلية
- الدفع الجديد عبر `POST /api/admin/invoices/:id/payments` متاح للإدارة والمدير والمحاسبة فقط.
- إعادة الطلب بنفس المفتاح والفاتورة والمبلغ تعيد نتيجة العملية السابقة دون إنشاء حركة أخرى؛ استخدام المفتاح لدفعة مختلفة يُرفض.
- يحتفظ النظام بسجل الحركة الأصلي، ويربط الدفعة بالفاتورة ويحدّث المدفوع والمتبقي وحالة الفاتورة.
- يظل اعتماد العقد منفصلًا عن إصدار الفاتورة وتسجيل التحصيل.
- تم تحديث رقم التطبيق إلى `2.10.46` ومخابئ التخزين المؤقت إلى `houshak-admin-v25` و`houshak-client-v17`.
