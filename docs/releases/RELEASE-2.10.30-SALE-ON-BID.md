# حوشك 2.10.30 — طريقة البيع «على السوم»

- إضافة اختيار طريقة تحديد سعر البيع: «سعر محدد» أو «على السوم» للأصول المعروضة للبيع أو للبيع والإيجار.
- عند اختيار «على السوم»، لا يُطلب مبلغ بيع ولا يُخزَّن السعر كصفر؛ تبقى قيمة السعر فارغة.
- تظهر العبارة «على السوم» في بطاقات الإعلانات وتفاصيل الأصل وصفحة QR العامة وسند استلام الأصل.
- يبقى حقل «السوم الحالي» منفصلًا عن طريقة السعر، وتظل عروض الشراء وسير الحجز كما هي.
- عند استخدام فلتر الحد الأدنى/الأعلى للسعر، لا تظهر أصول «على السوم» ضمن النتائج ذات النطاق الرقمي؛ أما البحث دون فلتر سعر فيعرضها كالمعتاد.
- لا يؤثر التعديل في الإيجار أو التخزين أو الأصول القديمة ذات السعر المحدد.
- تحديث ذاكرة التخزين المؤقت للعميل والإدارة.
