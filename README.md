# حوشك — منصة إدارة وعرض ووساطة المركبات والمعدات والأصول

نسخة 2.2.0 — مشروع Node.js مستقل وسهل النشر على GitHub وRailway.

## التشغيل المحلي
```bash
npm run seed
npm start
```
ثم افتح `http://localhost:3000`.

## الاختبار
```bash
npm test
```

## النشر على Railway
راجع `RAILWAY.md`. المشروع يحتوي على `railway.json` مع أمر التشغيل وفحص الصحة.

### التخزين
البيانات والصور تستخدم التخزين المحلي في هذه النسخة. على Railway يجب إضافة Volume وربط:
- `DATA_DIR=/data`
- `UPLOAD_DIR=/data/uploads`

## بيانات الدخول الأولية
- الجوال: `0500000000`
- كلمة المرور: `Admin@12345`

غيّر كلمة المرور فورًا.

## أبرز الوظائف
- إدارة الأصول والمالكين.
- توقيف وتخزين مع احتساب الرسوم حتى الخروج.
- البيع والإيجار والبيع والإيجار.
- حالات الحجز والبيع والتأجير والخروج.
- عروض الشراء وحجوزات الإيجار.
- مواقع الأصول داخل الحوش.
- الصور ومحاضر حالة الأصل.
- الفواتير والمدفوعات والحركات المالية.
- العقود والعمولات.
- التقارير وسجل التدقيق.
- المستخدمون والصلاحيات.
- التصنيفات الديناميكية.
- إعدادات اسم النظام والدولة والعملة وبيانات المنشأة.
- أنواع الهوية: هوية وطنية/شخصية، هوية مقيم، جواز سفر، هوية أخرى.

## إعدادات قابلة للتغيير
اسم النظام افتراضيًا `حوشك`، ويمكن تغييره من لوحة الإدارة إلى أي اسم مثل `عراج أبو حيدر`.

العملة الافتراضية `SAR`، ويمكن اختيار `YER` أو `USD` وغيرها من العملات المدعومة.

## ملاحظة تقنية
قاعدة البيانات في هذه النسخة JSON لتسهيل التشغيل المباشر. للاستخدام التجاري واسع النطاق يوصى بالترقية إلى PostgreSQL وتخزين الصور في Object Storage.

## v2.2.0 — الحجز بالعربون
- الحجز أصبح حالة تشغيلية وليست غرضًا مستقلًا.
- عند تأكيد الحجز يجب تسجيل مبلغ عربون أكبر من صفر.
- يتحول الأصل إلى `RESERVED` ويختفي تلقائيًا من الإعلانات العامة.
- حفظ السعر المتفق عليه والعربون وتاريخ دفع العربون.
- تسجيل العربون كحركة دخل.
- إلغاء الحجز يعيد الأصل إلى `ACTIVE` ويعيد ظهوره تلقائيًا حسب غرضه.
- إتمام حجز البيع يحول الأصل إلى `SOLD`، وإتمام حجز الإيجار يحوله إلى `RENTED` ويغلق الخروج.
- الزائر يستطيع طلب حجز لعروض البيع والإيجار دون إنشاء حساب.
- رقم واتساب أصبح يعتمد على مفتاح الدولة القابل للإعداد بدل تثبيت السعودية.
